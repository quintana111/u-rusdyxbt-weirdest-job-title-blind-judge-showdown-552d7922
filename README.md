## Entry

> Senior Penguin Relocation Coordinator for Divorcing Couples

A single job title, 59 characters, nothing else. A real-sounding senior
coordinator role with one hilariously specific twist: the relocations are
for penguins, and the clients are divorcing couples.

## How it works

`main.ts` writes exactly that title — and nothing else — to `entry.txt`
(or to the path in the `ENTRY_OUTPUT_PATH` environment variable).

```sh
node main.ts
cat entry.txt
```
